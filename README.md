# achyar99.github.io

Personal website of **Achyarul Mabruri (Ruri)**, M.S. researcher in Semiconductor & Nano Systems at Korea University.
Live at https://achyar99.github.io

Plain HTML, CSS and JavaScript; no framework.

## Edit and rebuild
Page content is generated by a local build script (kept on the author's computer, not in this repository).
To rebuild locally:

```bash
python3 _build/build.py
```

- `assets/css/style.css` — styles (light/dark, responsive)
- `assets/js/main.js` — menu, filter, timeline, lightbox
- `assets/img/`, `assets/fig/` — photos and research figures
- `assets/Achyarul_Mabruri_CV.pdf` — replace with a new CV of the same name
